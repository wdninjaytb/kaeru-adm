# 🐸 Kaeru Produtos Orientais — Admin Panel

[🇧🇷 Português](README.md) | 🇺🇸 **English** | [🇯🇵 日本語](README.ja.md)

Administrative panel developed as part of the academic project **Kaeru Produtos Orientais**, during the Analysis and Systems Development program at Centro Universitário Integrado.

This application represents the internal area of the system, responsible for managing the data used by the public Kaeru catalog.

## 📸 Preview

![Kaeru Produtos Orientais Admin Panel](admkaeru.png)

## ✨ Features

- Administrator authentication
- Session management
- Product registration
- Product editing
- Product deletion
- Category management
- Database integration
- Form validation
- Dashboard for monitoring inventory and system data
- Administrative interface separated from the public catalog

## 🛠️ Technologies

- PHP
- MySQL / MariaDB
- HTML
- CSS
- Bootstrap
- JavaScript
- PDO

## 🗂️ About the System

The administrative panel was developed separately from Kaeru's public interface.

It allows the data used by the catalog to be managed while keeping administrative operations separate from the interface intended for visitors.

The built-in dashboard provides an overview of products, categories and inventory information.

## ⚙️ Local Setup

The project uses PHP and MySQL/MariaDB and can be run locally using an environment such as XAMPP.

The database connection must be configured according to the local environment before running the application.
