# 🐸 Kaeru Produtos Orientais — 管理システム

[🇧🇷 Português](README.md) | [🇺🇸 English](README.en.md) | 🇯🇵 **日本語**

Centro Universitário Integradoの**システム分析・開発（ADS）**コースで制作した「Kaeru Produtos Orientais」大学プロジェクトの管理システムです。

このアプリケーションは、Kaeruの商品カタログで使用されるデータを管理するための内部システムとして開発しました。

## 📸 プレビュー

![Kaeru Produtos Orientais 管理システム](painel-admin-kaeru.png)

## ✨ 主な機能

- 管理者ログイン
- セッション管理
- 商品登録
- 商品編集
- 商品削除
- カテゴリー管理
- データベース連携
- フォームの入力検証
- 在庫やシステム情報を確認できるダッシュボード
- 公開カタログとは別に構成された管理インターフェース

## 🛠️ 使用技術

- PHP
- MySQL / MariaDB
- HTML
- CSS
- Bootstrap
- JavaScript
- PDO

## 🗂️ システムについて

管理システムは、Kaeruの一般ユーザー向けの商品カタログとは別のアプリケーションとして開発しました。

このシステムを使用して、商品カタログで表示されるデータを管理できます。これにより、管理機能と一般ユーザー向けのインターフェースを分けています。

ダッシュボードでは、商品、カテゴリー、在庫などの情報を確認できます。

## ⚙️ ローカル環境での実行

このプロジェクトはPHPとMySQL/MariaDBを使用しており、XAMPPなどのローカル開発環境で実行できます。

実行する前に、使用する環境に合わせてデータベース接続を設定する必要があります。

## 🎓 制作背景

**システム分析・開発（ADS）**コースの大学課題として制作したプロジェクトです。

管理システムの開発では、認証、セッション管理、CRUD操作、データベース連携、管理画面の制作などに取り組みました。

## ⚠️ 注意事項

このプロジェクトは、ブラジル・パラナ州カンポ・モウランにある実在の店舗 **Kaeru Produtos Orientais** の許可を得て、大学の学習目的で制作しました。

プロジェクト内の店舗情報は、開発時に許可を得て使用しています。

このリポジトリでは、大学での学習およびポートフォリオを目的としてソースコードのみを公開しています。このアプリケーションは店舗の公式管理システムではなく、公開サービスとしてホスティングされていません。
